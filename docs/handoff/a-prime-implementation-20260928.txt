## 3. §5.3 门禁的实施期重大修正

取证见 `docs/evidence/caliber-drift-gate-forensics-20260928.md`。要点：

1. **本地探测无法区分「云端口径漂移」与「缺陷1 污染未修」**——
   A′ 对 `stock_minutes` 不还原 → 本地表 = 云端值逐行直写，二者在本地叠加。
   实测 156 万配对：51.3% 逐位相等、median 比值 0.9993 + 膨胀长尾（p99 1.11/max 18.7）
   = 污染分布特征，非口径翻转。
2. **处置**：`_CALIBER_BLOCK_STOCK_MINUTES = False`（默认）→ 只告警不阻断，
   detail 如实标注；**数据修复验收通过后置 `True`** 恢复 §5.3 阻断语义。
   双态由测试双向固化（阻断/告警各一用例）。
3. **ETF 两表结构性不可探**（实测最大除权步进 1.925% < 2% 阈值），
   已如实分类为 `CaliberDriftNotProbeable`，口径交 §5.2 一致率兜底。

## 4. 实施中修复的 4 个实质缺陷（全部固化回归用例）

| # | 缺陷 | 后果 | 修复 |
|---|---|---|---|
| ① | 因子分割点误用 `ex-2d` | 2,070/2,441 code 误判「无步进」 | 分割点取 `ex_ms` |
| ② | bar 时刻过滤一表通吃 | 三张日线/ETF 表 **0 探针**（静默失效） | 按表选用时刻（分钟 15:00 CST / 日线 00:00 CST） |
| ③ | 探针取「窗口内最后两日」 | `stock_daily` 被误判 51% qfq | 严格「除权日 vs 前一交易日」+ CST 日对齐 |
| ④ | `gap≥2%` 阈值 | ETF 表结构性 0 探针却报「样本不足」 | 新增 `CaliberDriftNotProbeable` 如实分类 |
