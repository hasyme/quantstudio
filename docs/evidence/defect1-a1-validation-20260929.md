## 4. 运行期发现（须反馈方案，非方案缺陷）

1. **写阶段是主成本**（非 fetch）：单片 ~1.9 min，231 片 ≈ 7h。
   → 方案 §10.3「6 轮 × ~45min」低估；**A2 前须重算轮次**。
2. **`UnitCheck` 隔离告警**：每片约 55–58 行被 quarantine（`rules=['UnitCheck']`）
   —— 与本次修复无关的既有校验行为，但 **A3 验收须一并核查**是否影响一致率。
3. **强杀留陈旧锁**（我的看门狗用 `Stop-Process -Force` 绕过清理）：
   `data/snapshots/.write_lock` 残留，导致下一次启动 `WriteLockHeld` 失败。
   **处置**：已按 `pid` 判死清理；**后续轮次须改用「自然完成」或「优雅停止」**，
   避免手改锁文件。
