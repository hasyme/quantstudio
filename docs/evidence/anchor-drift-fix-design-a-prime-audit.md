## 1. 取证地基核验（全文命门）

A′ 的简化（一行 frozenset 判断）建立在「云端口径表级恒定」假设上。假设成立 → A′ 显然更优（最小、可逆、零依赖、零开销）；假设不成立 → A′ 对真异质 code 会**引入新缺陷**，比 v3 更危险。故取证强度 = A′ 命门。

### 1.1 etf_daily —— 证据等级 A，可作 qfq 基准

286 个 ratio≠1 样本，d_qfq 全部 ≈0（0.00%/0.02%/0.00%），cloud_close × adj_latest/adj_i 逐位吻合 raw。这是真正的决定性证据。该表 qfq 结论可信，A′ §2.2 把它纳入 `_QFQ_CALIBER_TABLES` 成立。

### 1.2 stock_daily —— 证据等级 B+，归因方向可信

16,029 样本中 raw 360 + OTHER 1,290 = 1,650 全部归 300803 单一 code，且日期范围分两段（raw 2025-03-17~2026-09-03 / OTHER 2019-11-18~2025-03-14）。剔除后 14,379/14,820 = 100%。归因**给定日期范围**，可复核。建议 A′ §1.3 引用此分组证据增强说服。300803 根因列入§7 未决项合理。

### 1.3 stock_minutes —— 证据等级 C，**样本覆盖不足（P0-2）**

107 样本来自 **3 code**（38/36/33 日）。缺陷1 的 stock_minutes 失真集体是 13,309 单元格、跨 8-9 月、含 600649（+1532%）、300182（108x）等多 code。**取证未说明这 3 code 是否覆盖失真集合。** 若 3 code 是校准 tol 用的正常 code（如 000012），则「107/107 全 raw」只能外推到「正常 code 的 cloud raw 稳定」，外推到「失真 code 段的口径」证据不足——而失真段恰恰是 A′ 必须正确覆盖的范围。

→ **N2**：公开取样 code 集 + 与缺陷1 失真 code 集合的交集。若不交集，须补失真 code 的 cloud 口径直判（从 landing parquet 取 ratio≠1 样本判 raw/qfq）。

### 1.4 etf_minutes —— **自相矛盾（P0-1）**

取证 §5.1 实测表：

| code | OTHER | qfq | raw | 主导 |
|---|---|---|---|---|
| 159325 | 0 | 0 | 78 | **恒 raw（异常）** |

但 A′ §1.3 口径矩阵把 etf_minutes 整表归为「恒 qfq」，§2.2 `_QFQ_CALIBER_TABLES` 纳入 etf_minutes。**结论与自己的证据冲突。**

A′ 的归因是「159325 本地参照失配导致误判 raw」。但此归因本身依赖「本地参照不可靠」假设，而 159325 的 raw 判定又用本地参照——**构成循环论证**：
- 用本地参照判 159325 → 判出 raw → 说判定不可靠 → 剔除 → 表级 100% qfq。

若云端对 159325 真返回 raw，A′ ×ratio 会放大 = **重新引入缺陷1**。证伪此假设的唯一路径是不经本地参照的独立 raw 真值（除权登记日推算 raw、或云端 raw 输出参数）。取证未提供。

→ **N1**：补独立证据。在补证前，etf_minutes 的 qfq 归类**不可信**，A′ 对该表的处理 = 赌注。

### 1.5 关于「剔异常即表内异质」的逻辑链

A′ 删除了 v3 的逐日判定，理由是「表内异质不存在」。但 A′ 自己的取证过程**剔除 3 个异常 code**——剔除行为本身即承认表内异质（至少对这 3 code）。若异质真实存在，A′ 对它们 = 按表级口径猜测性处理；若异质是本地参照失配（归因成立），A′ 才正确。

**这是 A′ 地基的根本张力**：它用「本地参照判定异常 code 的口径」来证明「本地参照不可靠」，进而删除本地参照判定。结论与论证手段冲突。
